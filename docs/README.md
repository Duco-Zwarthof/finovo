# Finovo Documentation

This directory contains all project documentation for Finovo.

The documentation defines the product vision, engineering standards, software architecture, terminology, feature specifications and development process.

Every contributor and AI agent should read these documents before making significant changes.

# Documentation Principles

Documentation should always remain:

- Accurate
- Consistent
- Up to date
- Implementation-driven
- Easy to navigate

Documentation is considered part of the implementation.

Whenever implementation changes, determine whether one or more documentation files should also be updated according to `DOCUMENTATION_RULES.md`.

---

# Contributing

Before making significant changes:

1. Read the documentation in the order listed above.
2. Follow the rules in `AGENTS.md`.
3. Reuse existing code whenever possible.
4. Keep the documentation synchronized with the implementation.
